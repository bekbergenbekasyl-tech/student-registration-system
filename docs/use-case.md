# Use Case: Студенттің пәнге тіркелуі
- **Актер:** Студент
- **Негізгі ағын:**
  1. Студент жүйеге кіреді.
  2. Қолжетімді пәндер тізімін ашады.
  3. Қажетті пәнді таңдап, тіркелу батырмасын басады.
- **Актер:** Эдвайзер
- **Негізгі ағын:**
  1. Эдвайзер студенттердің өтінімдерін көреді.
  2. Өтінімді растайды немесе кері қайтарады.
